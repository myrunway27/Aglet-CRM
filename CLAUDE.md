# Project memory

## Standing rules for kitchen / door jobs (Mozaik)

These apply whenever a kitchen job is uploaded or entered (e.g. via the
`mozaik-door-job` skill), on top of that skill's own standing preferences.

### Gola (handleless profile) doors are NOT full length

- If a kitchen job has a **Gola profile** on the doors (the user may say
  "Gola", "gola handle", "gola rail", or it may be transcribed as
  "goal assistant" / "goal assist"), those doors **must be cut down**.
  They are shorter than the full cabinet opening height to leave room for
  the Gola channel.
- Never enter Gola doors at full length. Before entering sizes, confirm
  which doors carry the Gola profile and reduce their **height** by the
  Gola deduction for that job. Use the deduction the user gives for the
  job; if none was given, ask once, then apply it to every Gola door.
- Widths are unchanged; only the height is reduced.
- Call out in the report-back which doors were cut down for Gola and by
  how much, so the user can sanity-check the cut list.
