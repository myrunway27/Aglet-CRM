# Project memory

## Standing rules for kitchen / door jobs (Mozaik)

These apply whenever a kitchen job is uploaded or entered (e.g. via the
`mozaik-door-job` skill), on top of that skill's own standing preferences.

### Required intake questions on EVERY new job

Before entering a single door size, ask the user these questions. Do this
on every job, even if the answer seems obvious from the cut list. The
Mozaik skill's "don't ask for confirmation" preference does NOT cover
these; the user has explicitly asked to be asked every time.

1. **Does this kitchen use the Gola system** (handleless aluminium
   profile) on any of the doors?
2. If yes: **which doors** carry the Gola profile (all of them, or only
   certain runs / uppers / lowers)?
3. If yes: **what is the Gola deduction** for this job, i.e. how much to
   take off the height of each Gola door?

Only start entering sizes once all three are answered.

### Gola system doors are NOT full length

- Gola doors are shorter than the full opening height to leave room for
  the Gola channel. Never enter them at full length.
- **Why this matters:** on Nadia's kitchen the Gola doors were entered and
  cut at full length, and every door had to be re-cut afterwards. Do not
  repeat that.
- Reduce the **height** of each Gola door by the deduction from question 3.
  Widths are unchanged.
- Call out in the report-back which doors were cut down for Gola and by
  how much, so the user can sanity-check the cut list before cutting.

### Terminology

"Gola" may be transcribed by voice input as "goal assistant" or
"goal assist". Treat those as "Gola system".
