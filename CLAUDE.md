# Project memory

## Standing rules for kitchen / door jobs (Mozaik)

These apply whenever a kitchen job is uploaded or entered (e.g. via the
`mozaik-door-job` skill), on top of that skill's own standing preferences.

### Gola system doors are NOT full length

- If a kitchen job uses the **Gola system** (handleless aluminium profile;
  the user may say "Gola", "Gola system", "gola profile", or it may be
  transcribed as "goal assistant" / "goal assist"), the doors **must be
  cut down**. They are shorter than the full opening height to leave room
  for the Gola channel.
- **Why this matters:** on Nadia's kitchen the Gola doors were entered and
  cut at full length, and every door had to be re-cut afterwards. Do not
  repeat that.
- Never enter Gola doors at full length. Before entering sizes, confirm
  which doors carry the Gola profile and reduce their **height** by the
  Gola deduction for that job. Use the deduction the user gives; if none
  was given, ask once, then apply it to every Gola door.
- Widths are unchanged; only the height is reduced.
- Call out in the report-back which doors were cut down for Gola and by
  how much, so the user can sanity-check the cut list before cutting.
